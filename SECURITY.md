# Security

Please report vulnerabilities in the TgPay Crypto service, its Merchant API or its MCP server privately
to **law@tgpaycrypto.com** — do not open a public issue. Include the affected endpoint and steps to
reproduce.

If your API token may have leaked, revoke or rotate it at once in
[@tgpaycryptobot](https://t.me/tgpaycryptobot) → Merchant API → your app.
